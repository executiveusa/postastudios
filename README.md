# Posta Studio

Open-source social media scheduling for creators and teams, self-hosted by The Pauli Effect.

Posta Studio lets you plan, schedule, and publish posts across social networks from one workspace, with automation, AI-assisted drafting, analytics, and team collaboration.

## Running it

Posta Studio is a Laravel application. See `compose.yaml` for the development stack and `compose.prod.yaml` for the production layout. Copy `.env.example` to `.env` and fill in your database, mail, and social-platform credentials.
